# Инструменты для анализа данных

В проекте собраны самостоятельные Python-реализации для работы с данными. Выберите нужную реализацию, подготовьте указанные для неё файлы и запустите из корня проекта.

## Подготовка

1. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/), если он ещё не установлен.
2. Откройте терминал в корне проекта.
3. Установите зависимости:

```bash
uv sync
```

## Запуск реализации

Укажите путь к `main.py` выбранной реализации относительно корня проекта:

```bash
uv run main.py ./путь/к/реализации/main.py
```

Если реализации требуются аргументы, укажите их после пути к скрипту. Файлы, необходимые для работы реализации, размещайте в её собственном каталоге.

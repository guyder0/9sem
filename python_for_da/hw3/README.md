# Использую uv, поэтому перед запуском скриптов надо запустить

```
uv sync
```

# Скрипты скачивания сайта:

```
# Приведены стандартные параметры запуска, можно запускать без параметров
download_sync.py--dist="data/" --latency=0.05 --timeout=3
download_async.py --dist="data/" --latency=0.05 --max_requests=10 --timeout=3
```

Время работы (со стандартными параметрами):
21.2052 c. (синхронный) vs 11.2508 с. (асинхронный)
Что, я уверен, связано с max_requests нежели latency из-за ограничений сети; скачка идет все-таки подольше чем 0.05 (у меня)

# Скрипты парсинга

```
# Приведены стандартные параметры запуска, можно запускать без параметров
uv run parse-sync.py --data="data/" --output="output/parsed.json"
uv run parse-async.py --data="data/" --output="output/parsed.json"
```

Время работы: 4.6116 с. (синхронный) vs 4.6127 c. (асинхронный)
Вероятно из-за того, что бОльшая часть работы приходится на парсинг, а не на чтение с диска (файлы крайне маленькие).
